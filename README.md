# Learn JavaScript Basics

This repository contains beginner-friendly JavaScript examples and exercises to help learn the fundamentals of the language.

## Contents

- **JS Basics.js** — Introduction to JavaScript syntax and core concepts
- **JS Variables.js** — How to declare and use variables (`var`, `let`, `const`)
- **JS Identifier rules.js** — Rules and conventions for naming variables and identifiers in JavaScript
- **JS Verify Setup.js** — Script to verify your JavaScript environment is set up correctly

## Getting Started

1. Make sure you have [Node.js](https://nodejs.org/) installed, or use your browser's developer console.
2. Clone this repository:
   ```bash
   git clone <repo-url>
   cd LearnPlaywright
   ```
3. Run any file with Node.js:
   ```bash
   node "Chapter_01_Basics/JS Basics.js"
   ```
   Or open the files in your browser and check the console output.

## Topics Covered

- JavaScript syntax and structure
- Variable declarations and scope
- Identifier naming rules and best practices
- Environment setup verification
